UniTasker — Інформаційна система управління завданнями (Kanban Task Tracker)
UniTasker — це високопродуктивний веб-застосунок для автоматизації персонального та командного тайм-менеджменту. Проєкт реалізує методологію Kanban, забезпечуючи наочне відстеження життєвого циклу завдань, динамічну фільтрацію, режим фокусування «Сьогодні», інтерактивний веб-інтерфейс з підтримкою темної теми та автоматичну генерацію аналітичних звітів у форматі CSV.

Архітектура та технологічний стек
Проєкт побудовано за класичною трьохрівневою архітектурою із чітким розмежуванням відповідальності між бекендом, реляційною базою даних та фронтендом.

Бекенд (Backend)
Python 3.13 / FastAPI: Високопродуктивний асинхронний веб-фреймворк для побудови RESTful API.

Uvicorn: ASGI-сервер для обробки мережевих запитів.

SQLAlchemy: Object-Relational Mapping (ORM) для безпечної взаємодії з базою даних через об'єктну модель Python.

Pydantic: Сувора валідація типів даних, схем запитів та відповідей.

Сховище даних (Database)
SQLite3: Реляційна база даних, що зберігається у файлі tasks.db. Забезпечує підтримку ACID-транзакцій та цілісність даних без потреби у зовнішньому сервері БД.

Фронтенд (Frontend)
HTML5 / CSS3 / JavaScript (ES6+): Чиста клієнтська реалізація без важких сторонніх фреймворків.

CSS Custom Properties (Variables): Динамічне перемикання кольорових палітр для адаптивної світлої та темної тем.

HTML5 Drag-and-Drop API: Інтерактивне перетягування карток між колонками статусу.

Fetch API / Async JavaScript: Асинхронний обмін даними з сервером без перезавантаження сторінки.

Основний функціонал
1. Інтерактивна Kanban-дошка
Розподіл завдань за трьома основними статусами: TODO (Заплановано), IN PROGRESS (У процесі), DONE (Виконано).

Інтуїтивний механізм Drag-and-Drop для зміни статусу завдання з автоматичною синхронізацією стану на сервері.

Динамічний лічильник кількості карток у кожній колонці.

2. Повний цикл управління завданнями (Full CRUD + Edit)
Створення: Модальне вікно для введення назви, детального опису (підзадач), пріоритету, дедлайну та кастомних тегів.

Читання: Автоматичне завантаження карток при ініціалізації та динамічне оновлення інтерфейсу.

Оновлення (Редагування): Повноцінне редагування наявних завдань (зміна назви, опису, пріоритету, дедлайну та тегів) через спеціальну форму, а також миттєва зміна статусу виконання через перетягування карток.

Видалення: Безпосереднє вилучення завдань із бази даних за унікальним ідентифікатором.

3. Деталізація та структурованість
Підтримка багаторядкового опису (зручно для фіксації списків підзадач).

Градація пріоритетів (Низький, Середній, Високий) із кольоровою ідентифікацією.

Прив'язка кінцевих термінів виконання (дедлайнів) із форматуванням за датою.

Система кастомних хештегів для категоризації предметних областей (наприклад, ЛР, Диплом, IoT).

4. Динамічний пошук та режим фокусування «Сьогодні»
Пошуковий рядок: Здійснює клієнтську фільтрацію карток у реальному часі одночасно за назвою, вмістом опису та тегами.

Today View (Вигляд «Сьогодні»): Спеціалізований смарт-фільтр, який в один клік ізолює на дошці лише ті завдання, дедлайн яких спливає сьогодні, а також прострочені завдання, що потребують негайної уваги.

5. Персоналізація інтерфейсу (Dark / Light Theme)
Вбудована підтримка темного та світлого режимів відображення для комфортної роботи у будь-який час доби.

Збереження обраної теми у системному сховищі браузера (localStorage), що зберігає налаштування користувача між сесіями.

6. Експорт даних у CSV (Excel-compatible)
Генерація звітів у форматі CSV на стороні сервера.

Включення маркера UTF-8 BOM (\ufeff) для коректного відображення кирилиці.

Використання крапки з комою (;) як розділювача колонок для повної сумісності з українською та європейською локалізаціями Microsoft Excel.

Автоматичне очищення багаторядкових описів від символів переносу рядка із заміною на розділювач | для збереження структури таблиці.

Модель даних та безпека збереження
Модель даних (Schemas & Models)
Взаємодія з даними базується на моделі DBTask:

id (String, UUID4): Унікальний первинний ключ.

title (String, min_length=1, max_length=100): Обов'язкова назва завдання.

description (Text, Optional): Розширений опис або перелік підзадач.

status (String, Default: "TODO"): Поточний стан виконання.

priority (String, Optional): Рівень важливості.

deadline (DateTime, Optional): Кінцева дата виконання.

tags (String, Optional): Текстовий рядок із тегами, розділеними комами.

created_at (DateTime): Автоматична мітка часу створення запису.

Забезпечення цілісності даних (Data Persistence)
Для запобігання втраті або пошкодженню даних при раптових збоях системи застосовано транзакційну модель SQLite. Всі операції запису виконуються через послідовність дій db.add() -> db.commit() -> db.refresh(). Валідація входів на рівні Pydantic гарантує, що порожні запити або запити з відсутніми обов'язковими полями відхиляються до моменту звернення до бази даних.

Інструкція із розгортання та запуску
Попередні вимоги
На комп'ютері має бути встановлено Python версії 3.10 або вище.

Крок 1. Клонування репозиторію
Bash
git clone https://github.com/kozaknikolay19-lab/UniTasker.git
cd UniTasker
Крок 2. Встановлення залежностей
Запустіть команду для встановлення необхідних бібліотек:

Bash
pip install fastapi uvicorn sqlalchemy
Крок 3. Запуск веб-сервера
Запустіть локальний сервер розробки Uvicorn:

Bash
uvicorn main:app --reload
Крок 4. Доступ до інтерфейсу
Відкрийте веб-браузер та перейдіть за адресою:http://127.0.0.1:8000

Інтерактивна документація API (Swagger UI) доступна за адресою:http://127.0.0.1:8000/docs
